# Feature Specification: Optional two-factor authentication at login

**Feature Branch**: `015-two-factor-auth-plan-drift`

## Functional Requirements

- **REQ-001**: System MUST let a customer opt into TOTP-based two-factor authentication.
- **REQ-002**: A customer with 2FA enabled MUST be prompted for a TOTP code after a correct password before login completes.
