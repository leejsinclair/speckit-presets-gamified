# Quest Story: Dark mode toggle

## Quest Title

Dark mode toggle

## Problem Statement

Users in low-light environments find the light-only interface uncomfortable to read.

## Who Is Affected / Actors

Users who prefer a dark color scheme.

## Current Behaviour

The interface only renders in a single light color scheme.

## Use Cases

1. User toggles dark mode in settings and the interface switches to a dark color scheme immediately.

## Desired Outcomes

Users can switch the interface to a dark color scheme.

## Scope Boundaries

**In-Scope**: a single dark color scheme, toggle in settings.
**Out-of-Scope**: per-page or per-component theme overrides.
**Adjacent Concerns**: custom user-defined color themes — not requested.

## Success Criteria

Toggling dark mode changes every screen's color scheme immediately, with no reload required.

## Assumptions & Known Unknowns

**Assumed**: nothing beyond what's stated above.
**Unknown**: nothing material identified.
