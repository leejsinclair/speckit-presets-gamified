# Feature Specification: Shortened links for shared URLs

**Feature Branch**: `010-url-shortener`

## Functional Requirements

- **REQ-001**: System MUST generate a short link for any given valid URL.
- **REQ-002**: A short link MUST redirect to its original URL when visited.
- **REQ-003**: A short link MUST be rejected as invalid if given a malformed input URL.

## Out of Scope

Vanity slugs and click analytics (story Adjacent Concerns — unchanged).
