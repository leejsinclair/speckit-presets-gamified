# Feature Specification: Shortened links for shared URLs

**Feature Branch**: `011-url-shortener-drift`

## Functional Requirements

- **REQ-001**: System MUST generate a short link for any given valid URL.
- **REQ-002**: A short link MUST redirect to its original URL when visited.
- **REQ-003**: System MUST provide a real-time analytics dashboard showing click counts, referrers, and geographic breakdown for every short link.
