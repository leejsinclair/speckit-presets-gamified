# Feature Specification: Self-service password reset

**Feature Branch**: `019-password-reset-rate-limited`

## Functional Requirements

- **REQ-001**: System MUST let a customer request a password-reset link by email.
- **REQ-002**: A reset link MUST allow the customer to set a new password.
- **REQ-003**: Reset-link requests for a single account MUST be rate-limited to prevent abuse of the email-sending mechanism.
