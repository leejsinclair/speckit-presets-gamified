# Changelog

All notable changes to this project are documented in this file.

## 1.0.0 - 2026-09-19

Initial release.

- `preset.yml` (root): `questmaster-pending-story` — prepends a pending-story check onto Spec
  Kit's core `spec-template.md`.
- `extensions/questmaster/`: the Questmaster extension — Socratic story-framing, banded Integrity
  scoring, the Judgment Ledger and Dragon Pass, the Comprehension Checkpoint, and Drift
  Classification across Story → Spec → Plan. See `questmaster.md` for the full methodology.
